# Paper artifacts

- `main_manuscript.pdf` — authoritative 23-page manuscript supplied by the authors.
- `main_manuscript.tex` — editable submission source synchronized with the authoritative main-manuscript content and current reviewer-facing figure filenames.
- `supplementary_material.pdf` — authoritative 5-page supplementary material supplied by the authors.
- `supplementary_material.tex` — editable source synchronized with the authoritative supplement content and reviewer-facing figure filenames.
- `references.bib` — bibliography archive corresponding to the manuscript references.
- `figures/` — source PDFs for the figures used in the manuscript and supplement.
- `text_exports/` — searchable plain-text exports of the two authoritative PDFs.

The main LaTeX source compiles to 23 pages and the supplementary LaTeX source compiles to 5 pages with the included figures.
