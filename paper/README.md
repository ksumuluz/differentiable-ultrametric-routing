# Paper artifacts

- `main_manuscript.pdf` — current 23-page submission manuscript, synchronized with the public-repository availability statement.
- `main_manuscript.tex` — editable submission source for the current main manuscript and repository figure filenames.
- `supplementary_material.pdf` — current 5-page supplementary material, synchronized with the public reproducibility repository.
- `supplementary_material.tex` — editable source for the current supplement and repository figure filenames.
- `references.bib` — bibliography archive corresponding to the manuscript references.
- `figures/` — source PDFs for the figures used in the manuscript and supplement.
- `text_exports/` — searchable plain-text exports of the two current submission PDFs.

The main LaTeX source compiles to 23 pages and the supplementary LaTeX source compiles to 5 pages with the included figures.
